# {{ title }}

## 挑戰

你目前的地圖服務供應商給你兩樣東西：

* 一組 `tiles`（正方形地圖影像，即圖磚），拼接在一起組成地圖
* 一套 JavaScript API，或行動應用程式的同等函式庫，用來檢視圖磚

要更換到開放街圖（OpenStreetMap），你需要替換這兩者。

## 圖磚

![圖磚](/assets/img/tiles.webp){ align=left .off-glb }
地圖圖磚（通常）是每張 256 x 256 像素的影像，從地圖資料庫繪製（「渲染」）而成。

如果你目前使用 Google 地圖，你用的是託管在 google.com 上的 Google 地圖圖磚。由於開放街圖基金會（OpenStreetMap Foundation）是資源有限的非營利組織，你不能直接改用 openstreetmap.org 的圖磚來替代（請參閱[圖磚使用政策](https://operations.osmfoundation.org/policies/tiles/){: target=blank}）。你可以改為：

* 下載免費的 OSM 地圖資料庫並自行渲染，產生自己的圖磚；

* 或使用第三方服務供應商（有些收費，有些免費）

OSM 地圖資料庫稱為 planet.osm。完整資料庫與定期更新檔皆可在 [planet.openstreetmap.org](http://planet.openstreetmap.org/){: target=blank} 取得。

自行渲染圖磚可讓你完全掌控其外觀，依喜好自訂地圖。或者，你也可以選擇第三方服務供應商：他們具備 OSM 專業知識，可能有現成的地圖樣式供你使用。

### 點陣圖磚或向量圖磚

點陣圖磚與向量圖磚是呈現與供給地圖資料的兩種不同方式，各有優點與適用情境。以下說明兩者的差異，以及各自的優勢與限制。

**點陣圖磚**

點陣圖磚基本上是地圖資料的影像，採用事先渲染方式產生不同縮放層級離散的影像檔案，以下為點陣圖磚的一些重點特性：

* 點陣圖磚以像素網格呈現地圖資料。每張圖磚都是一張靜態影像，描繪特定縮放等級下地圖的一部分。
* 點陣圖磚依據事先約定的樣式一旦產生有固定的外觀。要改變地圖的視覺呈現，就必須重新渲染圖磚，這可能耗費大量運算資源。
* 點陣圖磚相比向量圖磚有更大的檔案大小，因為每張圖磚都儲存像素層級的細節，導致需要更大的儲存空間，以及比較慢的下載時間。
* 點陣圖磚相當適合顯示複雜的製圖樣式，例如等高線地圖或是衛星影像，任何細節都很重要。
* 點陣圖磚的互動性有限，主要只有基本的縮放與平移。要與個別地圖圖徵互動或動態修改地圖外觀相當困難。

**向量圖磚**

另一方面，向量圖磚則以幾何圖徵（例如點、線與多邊形）的集合來呈現地圖資料。向量圖磚的特點如下：

* 向量圖磚以個別幾何與屬性儲存地圖資料，這些幾何圖形能即時被縮放、旋轉與重新套用樣式，能提供更為彈性與客製化選項。
* 向量圖磚允許動態樣式與地圖圖徵變動。樣式能即時變動，包括顏色、線條寬度、標籤取代，以及其他視覺屬性。
* 向量圖磚通常比點陣圖磚小，因為向量圖磚只會儲存幾何資料與屬性，因此只需較小的儲存空間，傳輸也比較快。
* 向量圖磚傳輸所需頻寬較少，因為只會傳送用戶端需要的地圖資料。這對行動應用程式或網路連線受限的地區特別有利。
* 向量圖磚允許豐富的互動功能以及即時渲染功能。使用者能與個別地圖圖徵互動，進行動態檢索，以及依據屬性套用客製化樣式，提供更具互動性與個人化的地圖體驗。

### 使用案例

選擇點陣圖磚或向量圖磚，取決於具體的使用情境與需求。這邊列出幾種常見適用不同情境的案例：

**點陣圖磚**

* 非對稱的詳盡地圖，例如等高線地圖或是衛星影像。
* 不需要即時互動或是時常更新的靜態地圖。
* 地圖資料相對穩定與不需要時常更動樣式的例子。

**向量圖磚**

* 需要即時客製化與互動的動態地圖，例如使用者指定的樣式或是篩選。
* 行動裝置或是有限頻寬的區域，或是儲存空間有限。
* 時常更動資料的地圖，需要即時反應更新狀態。

依據使用情境點陣圖磚與向量圖磚都有其優勢。點陣圖磚適合詳細顯示視覺化成果以及靜態地圖樣式，而向量圖磚則是適合動態變動樣式，互動以及傳輸資料時有效率。藉由瞭解這些圖磚類型的差異，你可以做出深思熟慮之下的地圖使用考量。

## API/函式庫

並且沒有單一包含全部功能的函式庫：您可以選擇任何適合您目的的品項，以下為兩樣最受歡迎用來顯示 OSM 圖磚的 JavaScript 函式庫：

* OpenLayers – 強大而且歷史悠久

* Leaflet – 輕量而且簡單易學

行動平台也有 API 能使用，例如 [Route-Me](https://github.com/route-me/route-me){: target=blank} (iOS) 以及 [osmdroid](https://github.com/osmdroid/osmdroid){: target=blank} (Android)。

## 授權條款

不像商業地圖供應商，開放街圖屬於‘開放資料’，您能夠免費取得地圖資料，自行複製與變動的自由。OSM 授權條款以[開放資料庫授權條款](http://opendatacommons.org/licenses/odbl/summary/){: target=blank}釋出。

您必須遵循的義務為：

* 署名。您必須用同樣使用商業地圖的顯著署名方式署名開放街圖，參見 [OSM 著作權指南](http://www.openstreetmap.org/copyright){: target=blank}。

* 相同方式分享。當您使用任何衍生編輯的 OSM 地圖資料，或是任何產製的產品，您必須將改衍生編輯的資料庫以 ODbL 授權條款釋出。
