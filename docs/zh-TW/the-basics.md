# {{ title }}

## 挑戰

你目前的地圖服務供應商會提供給你兩樣東西：

* 一組 `tiles`（正方形地圖影像，即圖磚），拼接在一起組成地圖
* 一套 JavaScript API，或行動應用程式的同等函式庫，用來檢視圖磚

要轉換到開放街圖（OpenStreetMap，OSM），你需要替換這兩者。

## 圖磚

![圖磚](/assets/img/tiles.webp){ align=left .off-glb }
地圖圖磚是從地圖資料庫繪製（「渲染」）而成，通常會是每張 256 x 256 像素的影像。

若你目前使用 Google 地圖，你所使用的即是託管於 google.com 的 Google 地圖圖磚。由於開放街圖基金會（OpenStreetMap Foundation，OSMF）是資源有限的非營利組織，你不應直接改用 openstreetmap.org 的圖磚來替代（請參閱[圖磚使用政策](https://operations.osmfoundation.org/policies/tiles/){: target=blank}）。你可以改為：

* 下載免費的 OSM 地圖資料庫並自行渲染，產生自己的圖磚；

* 或使用第三方服務供應商（有些收費，有些免費）

OSM 地圖資料庫稱為 planet.osm。完整資料庫與定期更新檔皆可在 [planet.openstreetmap.org](http://planet.openstreetmap.org/){: target=blank} 取得。

自行渲染圖磚可讓你完全掌控其外觀，依喜好自訂地圖。或者，你也可以選擇第三方服務供應商：他們具備 OSM 專業知識，可能有現成的地圖樣式供你使用。

### 點陣圖磚或向量圖磚

點陣圖磚與向量圖磚是呈現與提供地圖資料的兩種不同方式，各有優點與適用情境。以下說明兩者的差異，以及各自的優勢與限制。

**點陣圖磚**

點陣圖磚本質上是地圖資料的影像。它們在各縮放等級預先渲染，並儲存為個別的影像檔案。點陣圖磚的主要特性如下：

* 點陣圖磚以像素網格呈現地圖資料。每張圖磚都是一張靜態影像，描繪特定縮放等級下地圖的一部分。
* 點陣圖磚以預先定義的樣式產生，外觀固定。要改變地圖的視覺呈現，就必須重新渲染圖磚，這可能耗費大量運算資源。
* 點陣圖磚的檔案通常比向量圖磚大，因為每張圖磚都儲存像素層級的細節，需要更多儲存空間，下載速度也較慢。
* 點陣圖磚很適合顯示複雜的製圖樣式，例如地形圖或衛星影像等重視細節的地圖。
* 點陣圖磚的互動性有限，主要只有基本的縮放與平移。要與個別地圖圖徵互動或動態修改地圖外觀相當困難。

**向量圖磚**

向量圖磚則以幾何圖徵（例如點、線與多邊形）的集合來呈現地圖資料。向量圖磚的特點如下：

* 向量圖磚將地圖資料儲存為個別的幾何圖形與屬性。這些幾何圖形可即時縮放、旋轉與重新設定樣式，提供更多彈性與自訂選項。
* 向量圖磚可以動態設定樣式、修改地圖圖徵。樣式可隨時變更，包括顏色、線寬、標籤位置與其他視覺屬性。
* 向量圖磚通常比點陣圖磚小。由於只儲存幾何資料與屬性，所需儲存空間較少，傳輸也更快。
* 向量圖磚傳輸所需頻寬較少，因為只會傳送用戶端需要的地圖資料。這對行動應用程式或網路連線受限的地區特別有利。
* 向量圖磚支援豐富的互動與即時渲染。使用者可以與個別地圖圖徵互動、執行動態查詢，並根據屬性套用自訂樣式，提供更具互動性與個人化的地圖體驗。

### 使用情境

選擇點陣圖磚或向量圖磚，取決於具體的使用情境與需求。以下是各自擅長的情境：

**點陣圖磚**

* 細節豐富的精美地圖，例如地形圖或衛星影像。
* 不需要即時互動或頻繁更新的靜態地圖。
* 資料相對穩定、不需要經常修改或變更樣式的地圖。

**向量圖磚**

* 需要即時自訂與互動的動態地圖，例如由使用者決定樣式或篩選條件。
* 頻寬或儲存空間有限的行動應用程式或地區。
* 資料經常變動、需要即時反映更新的地圖。

點陣圖磚與向量圖磚依使用情境各有優點。點陣圖磚適合細緻的視覺呈現與靜態地圖樣式，向量圖磚則擅長動態樣式、互動性與高效率的資料傳輸。了解兩者的差異，有助於依需求挑選最合適的圖磚格式。

## API／函式庫

沒有單一的標準函式庫：你可以選擇最符合需求的。顯示 OSM 圖磚最熱門的兩個 JavaScript 函式庫是：

* OpenLayers —— 功能強大且歷史悠久

* Leaflet —— 輕巧且容易上手

行動平台也有可用的 API，例如 [Route-Me](https://github.com/route-me/route-me){: target=blank}（iOS）與 [osmdroid](https://github.com/osmdroid/osmdroid){: target=blank}（Android）。

## 授權條款

OSM 與商業服務供應商的資料不同，屬於「開放資料」。地圖資料免費提供，並可自由複製與修改。OSM 透過[開放資料庫授權條款（ODbL）](http://opendatacommons.org/licenses/odbl/summary/){: target=blank}授權。

你的義務是：

* 姓名標示。你必須標示開放街圖，標示方式應與使用商業服務供應商時一樣顯眼。請參閱 [OSM 的著作權指引](http://www.openstreetmap.org/copyright){: target=blank}。

* 相同方式分享。當你使用任何改編版本的 OSM 地圖資料，或以其製作的作品時，也必須以 ODbL 提供該改編後的資料庫。
